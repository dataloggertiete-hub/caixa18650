# Caixa 18650 3D

Configurador online para caixa de quatro células 18650 com suporte para DHT22. A página permite ajustar medidas e folgas, visualizar o modelo e exportar STL; as dimensões são apresentadas em milímetros (mm).

**Abrir o configurador:** https://dataloggertiete-hub.github.io/caixa18650/

Este repositório contém a versão estática servida pelo GitHub Pages.
